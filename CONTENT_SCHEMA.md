# Схема контенту модулів

Кожен модуль — окремий файл `js/modules/mNN.js` (NN = 01..14, `bonus.js`, `faults.js`).
Файл — звичайний скрипт (не ES-модуль), який додає об'єкт у глобальний масив:

```js
window.COURSE = window.COURSE || [];
window.COURSE.push({
  id: "m01",                 // унікальний, збігається з назвою файлу
  num: 1,                    // порядок у меню (bonus = 15, faults = 16)
  title: "Безпека: як не отримати удар струмом і не спричинити пожежу",
  short: "Безпека",          // коротка назва для меню (≤ 22 символів)
  intro: "1–2 речення: що вивчимо і навіщо.",
  goals: ["Після модуля ти зможеш ...", "..."],   // 3–6 пунктів
  lessons: [
    {
      id: "l1",              // унікальний в межах модуля
      title: "Назва уроку",
      html: `...`            // теорія, HTML-рядок (template literal)
    }
  ],
  practice: [
    {
      id: "p1",
      title: "Назва практичного завдання",
      kind: "calc" | "task" | "scheme" | "checklist" | "case",
      task: `HTML: умова`,
      // Для числових задач (необов'язково) — автоперевірка:
      answer: 7.27,          // число
      tolerance: 0.03,       // відносна похибка (0.03 = ±3%)
      unit: "А",
      hint: `HTML: підказка`,        // необов'язково
      solution: `HTML: повний розв'язок / еталонна відповідь`,
      sim: "builder"         // необов'язково: вбудувати в завдання конструктор схем (js/builder.js)
    }
  ],
  quiz: [
    {
      q: "Питання?",
      options: ["варіант 0", "варіант 1", "варіант 2", "варіант 3"],
      correct: 1,            // індекс правильного варіанта
      explain: "Чому саме так."
    }
  ]
});
```

## Доступні CSS-класи для HTML теорії

- `<div class="note">…</div>` — порада / інформація
- `<div class="warn">…</div>` — небезпека, попередження (червоне)
- `<div class="tip">…</div>` — практична порада (зелене)
- `<div class="formula">U = I · R</div>` — виділена формула
- `<div class="example"><b>Приклад.</b> …</div>` — розібраний приклад
- `<table>` — звичайні таблиці (оформлюються автоматично)
- `<ol class="steps">` — нумеровані покрокові інструкції
- `<figure class="scheme"><svg viewBox="…">…</svg><figcaption>…</figcaption></figure>` — схема.
  У SVG використовуй `stroke="currentColor"` / `fill="none"` для ліній і `fill="currentColor"` для тексту,
  щоб схема працювала у світлій і темній темі. Акцентні кольори: `var(--phase)` (фаза, коричневий/червоний),
  `var(--neutral)` (нуль, синій), `var(--pe)` (PE, жовто-зелений) — задавай як `style="stroke:var(--phase)"`.
- `<span class="tag">…</span>` — маленька мітка

## Конструктор схем

`js/builder.js` — вбудований конструктор: джерела (= і ~230 В), резистори, лампи, вимикачі (звичайний,
прохідний, перехресний), амперметр і вольтметр. Розрахунок — метод вузлових потенціалів, ~230 В
рахується як діюче значення для активного навантаження.

Завдання з `sim: "builder"` отримує кнопку «Зібрати схему в конструкторі». Початкові елементи
й автоперевірка задаються в `PRESETS` у `js/builder.js` за ключем `"<id модуля>/<id завдання>"`
(наприклад `"m07/p1"`). Без пресету відкривається порожнє поле без перевірки. Готові перевірки:
`checkSeries`, `checkParallel`, `checkMultiWay(c, прохідних, перехресних)`. Якщо перевірка пройдена,
завдання позначається виконаним. Окрема сторінка-пісочниця — `#/builder`.

## Планувальник квартири

Сторінка `#/planner`, код у `js/planner/` (порядок підключення в index.html важливий):

- `model.js` — проєкт (кімнати, прорізи, точки, групи, ПЗВ, щит), шаблони, розбір текстового опису, авторозстановка, траси і їх довжини, перевірки (`issues`), щит, специфікація, план робіт (`steps`).
- `wiring.js` — жили кабелів і з'єднання в коробках, на точках і в щиті.
- `load.js` — навантаження груп, падіння напруги, каталог приладів `DEVICES`, кондиціонер; доповнює `issues` і `steps`.
- `hints.js` — підказки «Чому так?» (`HINTS`: ключ → { t, h, l: [[модуль, урок]] }) і навчальний маршрут `TOUR`.
- `ui.js` — інтерфейс.

Кожне посилання на урок у підказках і кроках має вести на наявний урок. Значення в правилах — ті самі, що в уроках
(1,5 мм² — 10 А, 2,5 — 16 А, 4 — 25 А, 6 — 32 А; ПЗВ 30 мА на розетки, для ванної ≤ 30 мА, часто 10 мА).

## Правила

- Мова — українська, стиль простий, звертання на «ти».
- Оригінальний текст. Не копіювати з чужих курсів, не згадувати Choice31/IAMPM.
- Технічна точність: лише усталені значення (ПЗВ 30 мА для розеток, 10 мА для ванної/окремих
  ліній, 1,5 мм² Cu — освітлення / 10 А, 2,5 мм² Cu — розетки / 16 А, 4–6 мм² — плита тощо).
  Не вигадувати номери пунктів ПУЕ/ДБН. Де є варіанти — так і писати «зазвичай», «як правило».
- Кожна робота під напругою — лише після знеструмлення та перевірки відсутності напруги.
- У template literals не використовуй зворотні лапки (`) всередині тексту і `${` .
- Обсяг: кожен урок — повноцінна теорія (≈ 400–900 слів), з прикладами, таблицями, схемами де доречно.
