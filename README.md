# Електрика для дому: теорія і практика

Безкоштовний навчальний сайт з побутової електрики українською: 14 модулів теорії, практикум електрики під час ремонту квартири, бонусний блок розрахунків, банк із 30 кейсів несправностей і набір калькуляторів.

Статичний сайт без збирання: `index.html` + `css/` + `js/`. Контент кожного розділу — окремий файл у `js/modules/` (формат описано в [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md)).

Локальний запуск: `python -m http.server` у корені і відкрити http://localhost:8000.

> Матеріали навчальні й не дають кваліфікаційного розряду, групи з електробезпеки чи права самостійно виконувати електромонтажні роботи.
